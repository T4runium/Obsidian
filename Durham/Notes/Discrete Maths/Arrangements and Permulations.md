List or string in which order matters - finite
Length = number of items
Repetitions are allowed

**Standard Problem 1**  ([[Distinguishable balls and bins]])
How many arrangements of length k can be made from elements of set S size n
all arrangements = $|S|=n$
arrangements are just picking from the set so a [[Cartesian product]] of the set itself
$\therefore \text{Num of combinations }=|S|^k = n^k$
