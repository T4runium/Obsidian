Algorithm: A method or a process that can be followed to solve a problem.
	Should be correct.
	 Should be unambiguous. 	
	 Should be finite.

Data Structure:
	Particular way of storing  and organising data to be accessed and used efficiently .
		Good use of data structures makes good use of space and time.

Random Access Machines (RAM*):
	Memory is an infinite array.
	Instructions are executed sequentially.
	Instrcutions take unit time to execute.
