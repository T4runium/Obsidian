Number systems are usually:
	Additive - a tally
	Subtractive - subtract val for a larger val (roman numerals)
	Positional - each unit has a place with a given value

For a positional system:

$$
N =\sum_{i} b_{i}d_{i}
$$  where d is the digit and b is the base

Binary: base 2
computers use Binary as it is easy to represent using electricity (1 is on, 2 is off)
Max Value represented by n bits = $2^n - 1$

Hexadecimal = base 16
word - similar to byte or nibble. Its n bits for an n bit cpu

For a fractional Binary:

$V = \frac{N}{2^f}$  
where V is the value and f is the number of bits that are decimal

Same bits can have different meaning based on agreed interpretation
