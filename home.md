## My note style
- One concept per note, file named after the concept, filed under `Notes/<Module>/`
- Split lectures into small subtopic notes (e.g. Hash Tables → Hash Functions, Collision Handling, Linear Probing...), don't mirror the slide order
- Coursework notes go in `Notes/<Module>/Coursework/`, kept apart from concept notes
- Definition first, then properties, proofs and examples
- Heavy LaTeX: inline `$...$`, display `$$...$$`, multi-step proofs in `\begin{aligned}` with `\therefore`
- **Bold** key terms
- `#` headings for sub-topics (e.g. `# Standard problem 3`, `# Proposition`, `# Chain Rule`)
- Block links to specific results: `[[Groups#^41920a|inverse]]`, `[[Arrangements#^0a665c|SP2]]`
- Short and casual, no frontmatter, no tags
- Plugins: Latex Suite, Obsidian Git (auto backup), Color Folders
