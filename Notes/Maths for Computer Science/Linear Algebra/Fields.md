A field is a set F with two operations, usually addition and subtraction such that:
- Addition and Multiplication are both [[Groups#^27c6ec|associative]]  
- Addition and Multiplication are both cumulative
- There is a additive and a multiplicative [[Groups#^5a8c2e|identity]] 
- Every element has an additive [[Groups#^41920a|inverse]]
- every element except 0 has a multiplicative [[Groups#^41920a|inverse]] 
- Multiplication distributes over addition
$$
a(b + c) = ab + ac 
$$
Every field has 2 [[Groups]]:
- an additive group (F, +)
- a multiplicative group (F / {0}, X)

To have a field, we need:
- 2 operations
- compatibility between operations via distribution
- multiplicative inverses for all non-zero elements
