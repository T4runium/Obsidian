For a function $f: A \to B$:
- $A$ is the domain of $f$
- $B$ is the co-domain of $f$
- if $f(a) = b$ then $b$ is the image of $a$
- The pre-image of b is the set $\{a:f(a) = b\}$
- The image or range of $f$ is $\{f(a) : a \in A\} \subseteq B$

Compositions of functions:
If $f: A \to B$ and $g: B \to C$
Then $g \circ f: A \to C$ where $(g \circ f)(x) = g(f(x))$

**Injection** - 1 to 1: each element of A has a unique element in B (a [[Hash Tables|hash function]] with collisions is not injective)

**Surjection** - for all $b \in B, \exists  a \in A$ all values of B have a value of A leading to them

**Bijection** - both **Injective** and **Surjective** 

# Inverse Functions
If $f: A \to B$ then the inverse is $f^{-1}: B \to A$ **if** it exists
- $f$ must be injective  $\to$ Can't have 2 results
- $f$ must be surjective $\to$ some values of B won't have A values
- $\therefore$ must be **bijective**

If a function is bijective, $|A| = |B|$ (for infinite sets, this is what same size means)
