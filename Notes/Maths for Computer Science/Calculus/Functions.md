For a function $f: A \to B$:
- $A$ is the domain of $f$
- $B$ is the co-domain of $f$
- if $f(0) = b$ then $b$ is an image of $a$
- The pre-image of b is the set $[a:f(a) = b]$
- The image or range of $f$ is $A$

Compositions of functions:
If $f: A \to B$ and $g: B \to C$
Then $A \to C = g(f(x))$

**Injuction** - 1 to 1: each element of A has a unique element in B

**Surjection** - for all $b \in B, \exists  a \in A$ all values of B have a value of A leading to them

**Bijection** - both **Injective** and **Surjective** 

# Inverse Funtions
If $f: A \to B$ then the inverse is $f_{-1}: B \to A$ **if** it exists
- $f$ must be injuctive  $\to$ Can't have 2 results
- $f$ must be surjective $\to$ some values of B won't have A values
- $\therefore$ must be **bijective**

If a function is bijective, either $|A| = |B|$ if finite or both A and B are countable inifites
