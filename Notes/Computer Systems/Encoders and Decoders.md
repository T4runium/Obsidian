Decoder converts in input of $n$ bits and gives an output of $2^n$ bits
Decoder = $n \to 2^n$

Encoder is an opposite of decoder and takes in an input of $2^n$ bits and an output of $n$ bits
Encoder = $2^n \to n$

# Multiplexer

A multiplexer has a selector line that selects which input to use for the output (like a railway track switch). It has $n$ selector lines for $2^n$ lines

it allows for multiple inputs to be converted into one output

# Tristate
 A Tristate can output 3 distinct electrical states,  high voltage (1), low voltage (1) and high impedance (Z). 

Tristates are not useful by themselves, they need a tristate buffer and an encoder to enable just one of them.

# ALU
An ALU takes 2 operands and function code and returns the result
